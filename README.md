# Bus-t in Time

Bus-t in Time is a Java console-based fleet operations and dispatch system.

## Features

- Register drivers
- Register vehicles
- Add route schedules
- View drivers
- View vehicles
- View routes
- Dispatch vehicles
- Complete trips
- View dispatch records

## Requirements

- Java JDK
- Java IDE such as IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open the src folder.
4. Locate the main.java file.
5. Run the main class.
6. Follow the instructions shown in the console.

## Project Structure

- src/ – contains the Java source code
- .idea/ – IntelliJ IDEA project settings
- .gitignore – specifies files Git should ignore
- Main.iml – IntelliJ project configuration
- README.md – project information and running instructions
